# Screen-recording GIFs for the "Import the notebook" page

Drop each GIF here with the exact filename below. The page
(`pages/setup_notebook.html`) will pick them up automatically — no code
changes needed. Until a file exists, the page shows a dashed "Screen
recording" placeholder with the same caption.

| Filename | What it should show |
|---|---|
| `import_notebook.gif` | Workspace ▸ Home ▸ ⋯ ▸ Import ▸ drop the `.py` ▸ Import |
| `attach_compute.gif`  | Top-right compute selector ▸ choosing **Serverless** |
| `set_widgets.gif`     | Running cell 1, then setting the `catalog` / `schema` widgets |
| `run_all.gif`         | Clicking **Run all** and cells completing |
| `confirm_tables.gif`  | Catalog ▸ your catalog ▸ `energy_trading` ▸ the 10 tables |

Tips for recording:
- Keep them short (5–15s) and cropped to the relevant panel so the GIF stays small.
- Aim for < ~5 MB each so the page (and GitHub Pages) loads fast.
- 1× speed is fine; a subtle cursor highlight helps show where to click.
