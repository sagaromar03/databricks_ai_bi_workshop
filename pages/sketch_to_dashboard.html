Sketch to dashboard

Have a rough layout in mind? Sketch it on paper, hand the photo to AI/BI Genie, and let it build the dashboard for you — no dragging widgets around.

Before you start: you need a dashboard with the energy_trading dataset already added (see Step 3 · Create a dashboard) and a running SQL warehouse.

From sketch to dashboard

  1. Download the sketch

    Grab the hand-drawn layout sketch and save it to your computer — you'll hand this image to Genie.

    Download the sketch (.jpeg) ↓

    Or use your own — any photo of a dashboard layout works.

  2. Open Edit dashboard

    Open the dashboard in edit mode so you can add to it.

    • Open your dashboard and click Edit draft / Edit dashboard at the top.

  3. Add a new page

    Give the sketch its own blank page so it doesn't disturb your existing one.

    • Next to the page tabs, click + to add a new page.
    • (Optional) rename it, e.g. From sketch.

  4. Attach the sketch in Genie

    Hand the image to Genie and let it read the layout and build the widgets.

    • Open the Assistant / Genie panel and click the attach (📎) button.
    • Pick the sketch_to_dashboard.jpeg from your Downloads.
    • Add a short prompt if you like (e.g. build this dashboard from the sketch) and press Enter.
    • Wait while Genie reads the sketch and lays out the widgets — the dashboard builds itself.
Tip: the clearer the sketch — labelled boxes, rough grid, a title — the closer Genie gets. You can always follow up with more prompts to tweak what it built.
