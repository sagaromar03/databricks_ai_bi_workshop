Create an AI/BI dashboard

With the energy_trading tables built, turn them into an interactive AI/BI dashboard in Databricks — add a dataset, then just ask AI/BI Genie to generate the chart, KPI and filter in plain language, and publish it to share.

Before you start: you need the energy_trading tables in your catalog (see Step 2 · Import the notebook) and a running SQL warehouse — on Free Edition the Serverless Starter Warehouse is available by default.

Build the dashboard

  1. Create a new dashboard

    Start a blank AI/BI dashboard to build on.

    • In the left sidebar, click New → Dashboard (or open Dashboards and click Create dashboard).
    • Give it a name, e.g. Energy Trading — Activity.

  2. Add a dataset

    A dataset is the data your widgets read from. Add one straight from Unity Catalog — no SQL needed.

    • Open the Data tab at the top of the dashboard, then click Add data.
    • In Add data from Unity Catalog, browse to energy ▸ energy_trading and pick the energy_trading_metrics metric view (or any table), then click Add.
    • It appears in the Data Model with its measures and fields ready to use. (Prefer SQL? Use Add SQL dataset instead.)

  3. Ask Genie for a counter

    Build the widgets by describing them in plain language — no manual field-picking. Start with a headline number.

    • Open the Assistant / Genie panel on the dashboard.
    • Type a request — e.g. add a counter for total number of trades — and press Enter.
    • Genie generates the counter; add it to the canvas.

  4. Ask Genie for a chart

    Add a visualization the same way — just describe it.

    • In Genie, type add a bar graph for total trades by commodity and color it by direction and press Enter.
    • Add the generated chart to the canvas and position it next to the counter.

  5. Try a few power prompts

    Genie can shape the whole page, not just one widget at a time. Copy any of these and paste it into the Genie box:

    Make all the existing and future widgets with curve 12. And configure decimal places to exact 2.

    Add a text box at the top with 7*2 grid make heading as Executive Summary. And generate description for this page, not more than 15 words.

    add counter for total number of unique traders, counter for unique counter parties, add counter for total revenue

  6. Ask Genie for a filter

    Let viewers slice the whole dashboard — ask Genie to add the control.

    • In Genie, type add a filter for country and trade date at the top (or any field) and press Enter.
    • Add the filter to the canvas; the chart and counter update as you change it.

  7. Publish

    Share the finished dashboard.

    • Click Publish at the top-right.
    • Choose who can view it, then open the published link to see the live dashboard.
Tip: keep the first dataset broad (one query with the columns you need) and build several widgets on top of it — it's faster than a query per widget, and the filter then drives them all at once.
