Create a Genie agent

Point an AI/BI Genie space at the energy_trading tables so anyone can ask questions in plain English and get charts and answers back — no SQL required.

Before you start: you need the energy_trading tables in your catalog (see Step 2 · Import the notebook) and a running SQL warehouse. Free Edition includes Genie.

Create the Genie agent

  1. Create a new Genie agent & pick your data

    The only thing Genie asks for up front is the data — it auto-configures almost everything else.

    • In the left sidebar, open Genie and click New.
    • When prompted, select your energy_trading datasets — fact_trade and the dimensions (and energy_trading_metrics if you built it).
    • Open Configuration to see what Genie set up for you — instructions, sample questions and settings are already filled in.

  2. Ask your first question

    Type a question in plain English and see the answer, the chart, and the SQL Genie wrote.

    • Type or click a question — e.g. Show VWAP by Country Name — and press Enter.
    • Wait for the chart, then expand the SQL to see how Genie got there.

  3. Sharpen it (optional)

    Genie picks sensible defaults, but a few instructions make it noticeably more accurate. Open the Configure panel → Instructions and paste the block below (trim any line that references a table you didn't select).

    This agent answers questions about a market-wide energy trading dataset (energy_trading) — a tape of trades across power, gas, oil and carbon, as an exchange or regulator would see it, not a single firm's book. Measures & source of truth - Prefer the `energy_trading_metrics` metric view for standard measures (VWAP, volumes, notional, etc.). Its definitions are correct and consistent — use it instead of hand-rolling aggregations when a matching measure exists. Money & currencies - Values mix EUR, GBP and USD. To compare or total money in one currency, convert to EUR using `dim_fx_rate` (join on `currency_code`, multiply by `rate_to_eur`). - Never sum notional/value across currencies without converting first. Default money answers to EUR. Business rules - Exclude trades with `status = 'CANCELLED'` unless the user explicitly asks about cancellations — they inflate volumes and counts. - "Market-wide" = every participant. Do not assume one company; trader/company/desk live in `dim_trader`. - Some delivery points have no country and show up as "Unknown" — keep them, but call it out when it matters. Model & joins - Geography is snowflaked: to get country/continent, go delivery point → `dim_geography` (via `geography_key`). - Currency lives on `dim_instrument.currency`; join to `dim_fx_rate.currency_code` for EUR. Vocabulary - VWAP = volume-weighted average price. - "below/above market" = a trade's price vs the market reference price for the same delivery point and time. - direction = BUY/SELL; notional = price × volume in the trade's currency.

    • Then add a few sample questions — copy from the Genie question bank.

  4. Revisit your chat history

    Every conversation is saved — reopen a past chat to see its questions, answers and SQL again.

    • Click the history (clock) icon at the top-right, next to Configure.
    • Pick any past chat to reopen it exactly where you left off.

  5. Share it

    Let your team ask their own questions of the data.

    • Click Share, add the people or groups who should have access, and set their permission.
    • Or use Copy link to send it directly.
Tip: the clearer your instructions and sample questions, the better Genie does. Start with the ready-made prompts in the Genie question bank.
