Create a Genie agent

Point an AI/BI Genie space at the energy_trading tables so anyone can ask questions in plain English and get charts and answers back — no SQL required.

Before you start: you need the energy_trading tables in your catalog (see Step 2 · Import the notebook) and a running SQL warehouse. Free Edition includes Genie.

Create the Genie agent

  1. Create a new Genie agent & pick your data

    The only thing Genie asks for up front is the data — it auto-configures almost everything else.

    • In the left sidebar, open Genie and click New.
    • When prompted, select your energy_trading datasets — fact_trade and the dimensions (and energy_trading_metrics if you built it).
    • Open Configuration to see what Genie set up for you — instructions, sample questions and settings are already filled in.

  2. Ask your first question

    Type a question in plain English and see the answer, the chart, and the SQL Genie wrote.

    • Type or click a question — e.g. Show VWAP by Country Name — and press Enter.
    • Wait for the chart, then expand the SQL to see how Genie got there.

  3. Sharpen it (optional)

    Genie picks sensible defaults, but a few instructions and examples make it noticeably more accurate.

    • Open Instructions / settings and add the key framing: this is a market-wide trade tape; money mixes EUR/GBP/USD (join dim_fx_rate to convert); exclude CANCELLED trades.
    • Add a few sample questions — copy from the Genie question bank.

  4. Share it

    Let your team ask their own questions of the data.

    • Click Share, choose who can access the agent, and send them the link.
Tip: the clearer your instructions and sample questions, the better Genie does. Start with the ready-made prompts in the Genie question bank.
