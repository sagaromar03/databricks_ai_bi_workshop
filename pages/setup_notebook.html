Step 2 · Import the notebook and build the tables

With your free workspace ready, load the notebook, run it on serverless compute, and build all 10 energy_trading tables.

Download the notebook (.py) ↓

Load the notebook and build the tables

  1. Download the notebook

    From this repo, download energy_trading_workshop.py from the notebook/ folder and save it somewhere you can find it. It's a Databricks Python source file (.py) — import it directly, no need to open or convert it locally.

  2. Import it into your workspace

    Bring the notebook file into Databricks. It lands as an editable notebook in your home folder.

    • In the left sidebar, click Workspace, then open your Home folder (or any folder you own).
    • Click the ⋯ kebab menu at the top-right of the folder (or right-click the folder) → Import.
    • Keep source set to File, then drag the .py in or Browse to it, and click Import.
    • The notebook opens automatically once the import finishes.

  3. Attach serverless compute

    The notebook needs compute to run. On Free Edition, serverless is the only option — there's nothing to size or start.

    • With the notebook open, look at the compute selector in the top-right toolbar.
    • Click it and choose Serverless. It spins up on its own the first time you run a cell.

  4. Create and set the widgets

    The notebook is parameterised with widgets so you can point it at a catalog you can write to.

    • Run the first cell — it creates the widgets, which appear as a bar across the top of the notebook.
    • Set catalog to a catalog you can write to (on Free Edition, workspace works).
    • Leave schema as energy_trading.
    • Optional: pin date_end to a fixed date so the synthetic data is reproducible.

  5. Run all cells

    This is the step that actually builds the data. It generates the synthetic trades and writes the tables.

    • Click Run all at the top of the notebook.
    • The notebook writes 10 tables into <catalog>.energy_trading (plus the finance schema if you run Part 5).
    • The first run takes a few minutes while serverless warms up — later runs are faster.

  6. Confirm the tables

    Check the build succeeded before moving on to explore the data.

    • Open Catalog in the sidebar and expand your catalog → energy_trading.
    • Confirm the tables are present — the 10 core tables, plus a few helper views.
    • Then explore them with the interactive ER diagram and the Genie question bank.
Good to know: Free Edition is serverless-only and quota-limited, so very large regenerations may hit daily limits — the default settings in the notebook are well within range. If a run pauses, wait and retry, or reduce the date range. Free Edition also includes Genie, so you can point a Genie space at energy_trading straight after the tables build.
